# NSCCSRM Technical Recruitment – Task 1

## Signup Form with Validation and Dashboard

This project is created as part of the **NSCCSRM Technical Recruitment Task 1**.

The project is a simple web application that allows users to sign up using a username, email, and password. The entered details are validated and stored in the browser's `localStorage`.

## Features

- User Signup Form
- Username validation
- Email validation using Regular Expression (Regex)
- Password validation (minimum 6 characters)
- Password hashing using SHA-256
- User details stored in `localStorage`
- Dashboard displaying registered users
- Delete button to remove users from the dashboard
- Simple and responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
- Web Crypto API
